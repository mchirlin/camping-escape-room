## Campsite Layout

```
[Bathroom/Mine] — up the hill with stones
        |
   [Campsite + Tent (crafting table inside)]
        |
   [Tiny stream — fishing spot, gold blocks nearby]
        |
   [Forest entrance]
        |
   [Trail → Larger stream]
```

## Decisions

### Crafting Table
- Inside the tent — home base, sheltered from weather
- Kids keep returning here between explorations

### Biome Locations
- **Forest biome** (wood planks, sticks): near trees around campsite and forest entrance
- **Mine biome** (paper, string, copper, coal): bathroom up the hill
- **Quarry biome** (iron, emerald, amethyst via villager): stone pile area — Diamond Pickaxe required
- **River biome** (diamonds fished, sand on shore): in/near the tiny stream
- **Trail/deep forest**: creeper location

### Creeper Location
- Along the trail in the forest — kids won't go deep into the forest until the sword clue sends them there
- Hidden from initial view so they don't mess with it early

### Treasure Chest (finale)
- Locked chest inside the tent, in plain sight from the start ("💥 TNT Required" sign)
- Opened by the crafted TNT — holds the Ender Dragon egg + treats
- No dig site: the egg is in the chest, not buried. (Legacy versions had a buried
  dig site + diamond shovel — that's no longer part of the design.)

### Decorations
- Minimal — one or two Minecraft-style biome signs (pixel font)
- Let the natural setting do most of the work

### Bathroom/Mine
- One dedicated bathroom stall with door to outside
- Only group using the facilities — no conflict with other campers
- Sign on door: "⛏ Abandoned Mine — Cobblestone Pickaxe Required"
- Blocks hidden inside on ledges, behind fixtures, in corners
