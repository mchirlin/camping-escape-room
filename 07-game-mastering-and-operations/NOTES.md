## Decisions

### Roles
- **Game master (dad):** home base at the crafting table in the tent; verifies
  tool-gated locations, controls the map admin screen and soundboard.
- **Co-host (helper):** plays the Villager, reloads the crafting-table doors with
  the next prop between crafts, gatekeeps locations, and helps with sound/drama.
  Only hands something to the kids during the emerald trade. See the co-host
  briefing for the full breakdown.

### Operation
- Two adults now (was originally planned solo)
- Stay near the crafting table (in the tent) as home base
- Walk with kids to key moments (mine entrance, creeper) as needed

### Hints
- Just walk over and nudge them if stuck
- Keep it casual — no formal hint system needed for friends and family

### Intro Speech Ideas
- **Diary approach (recommended):** Use the diary as an explorer's journal. Read
  the last entry aloud — it describes the Ender Dragon egg near the campsite.
  Hand them the journal + the Crafting Table recipe card, and send them to find
  4 oak planks. Those planks unlock the tent and the first craft (the tutorial).
- **Simple version:** Gather kids, 30-second pitch: "There's an Ender Dragon egg
  hidden at this campsite, locked away. You'll craft tools to reach it. First,
  find 4 oak planks." Hand out the Crafting Table recipe card.

### Running Twice
- Want to run it for two groups
- Reset plan:
  - Take blocks back after each craft (already planned)
  - Re-stack creeper boxes (pre-scored for easy reassembly)
  - Re-hide blocks in same spots
  - Re-lock the treasure chest with a fresh egg + treats inside
  - Reset the crafting table + map fog; reload the door props in order
  - Reload recipe scrolls / journal pages
